# RSVP DXB mobile app

One Expo and React Native project powers both the Android and iOS apps. The shared screens, navigation, and app logic live in this repository; platform-specific settings are in `app.json` and native build settings can be generated by Expo when needed.

The customer app talks to the existing RSVP admin API for live events and member actions. The mobile app does not contain database credentials. The admin dashboard and customer website remain separate projects.

## Project layout

- `src/` — mobile app screens and shared app code
- `assets/` — app icons, images, and video
- `app.json` — Expo configuration and Android/iOS app identifiers
- `eas.json` — Android and iOS cloud build profiles
- `android/` — Android native project files
- `ios/` — generated by Expo when required; native iOS builds require macOS or EAS Build

## Run locally

Requirements: Node.js and npm. Install dependencies and start Expo:

```bash
npm install
npx expo start
```

Use Expo Go to scan the terminal QR code. To open a platform directly, use `npm run android` or `npm run ios`. An iOS simulator and local iOS builds require macOS; on Windows, use an iPhone with Expo Go for development or EAS Build for a native iOS build.

## Build for Android and iOS

Install and sign in to EAS CLI:

```bash
npm install --global eas-cli
eas login
```

Build either platform from this same repository:

```bash
eas build --platform android --profile production
eas build --platform ios --profile production
```

The preview profile creates an Android APK for internal distribution. The production Android profile creates an app bundle. iOS distribution requires Apple Developer credentials; Play Store distribution requires a Google Play developer account. Submit completed builds with `eas submit --platform android` or `eas submit --platform ios`.

## App identifiers and API configuration

The current Android application ID and iOS bundle identifier are both `com.rsvpdxb.app`, configured in `app.json`. Confirm these identifiers are available under your store accounts before publishing; store app identifiers cannot be changed after an app is created there.

The mobile API defaults to `https://d1f5sjkm09kt76.cloudfront.net`. Set `EXPO_PUBLIC_RSVP_API_URL` in the EAS environment to use another deployment. Deploy the admin service endpoints `/api/mobile/venues`, `/api/mobile/password`, and `/api/mobile/password-reset` and ensure its database has the `member_sessions` and `event_rsvp_requests` tables before releasing a build.

Before store release, set `WHATSAPP_NUMBER` and the real social links in `src/content.ts`.
